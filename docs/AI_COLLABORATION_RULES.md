# How to work with me on this project

- I am learning system design concepts as I build this. Do not generate
  a full module in one response.
- Before writing any code for a new piece, explain: the problem it solves,
  why this approach vs alternatives, and what would break without it.
- Build one layer at a time when I ask (e.g. schema, then repository,
  then service, then controller) — wait for me to confirm understanding
  before moving to the next layer.
- When I ask "what would break if I removed X", give a real, specific answer.
- Prefer plain, explicit code over clever abstractions — I need to be able
  to explain every line in an interview.
